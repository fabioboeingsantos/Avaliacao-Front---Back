Prepare pedido_cesta ou consulta_cestas. Respeite exclusões; se quantidade não foi dita, sugira 1. Para repetir, use somente uma cesta do histórico autorizado. Para cesta pronta, use a composição pequena: alface,tomate,cenoura,batata,cebola; média adiciona couve,beterraba,abobrinha; grande adiciona chuchu,pimentao,pepino,mandioca, uma unidade cada. Se faltar tamanho ou houver ambiguidade, retorne proposta null e uma pergunta.
